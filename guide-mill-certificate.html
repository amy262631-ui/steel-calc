材質證明書（Mill Certificate）完整解說：如何看懂、為什麼重要

深入介紹鋼材材質證明書（Mill Certificate / Test Certificate）的格式、關鍵欄位解讀，以及工程採購與驗收時的應用說明。

1. 什麼是材質證明書？

材質證明書（Mill Certificate，又稱Mill Test Report / MTR，中文稱「材質報告書」、「材料試驗證明書」）是鋼鐵廠出具的品質文件，記錄一批（爐次/Lot）鋼材的化學成份與機械（力學）性質實測數據，由製造廠加蓋公司章及授權人員簽章，作為品質合格的官方佐證。依合約規定，鋼材若無材質書或材質書不符規格，業主有權拒絕驗收。

2. 材質證明書主要欄位

欄位說明重要程度
廠商名稱鋼鐵廠全名及廠址★★★
爐次號碼 (Heat No.)每爐鋼水的唯一識別碼，可追溯生產批次★★★★★
材質規格 (Grade)如SS400、SN400B、A36、304等★★★★★
產品尺寸厚度、寬度、長度或型號★★★★
化學成份C、Si、Mn、P、S、Ni、Cr、Mo等各元素含量(%)★★★★★
降伏強度 (YS/ReL)開始永久變形的應力，MPa★★★★★
抗拉強度 (TS/Rm)最大承受拉力，MPa★★★★★
延伸率 (El%)斷裂時的伸長比率，%★★★★

3. 如何驗讀化學成份

以SS400鋼板（CNS 2473）為例：

元素規範上限 (%)材質書實測值範例結論
C（碳）≤0.230.15✅ 合格
Si（矽）≤0.350.22✅ 合格
Mn（錳）≤1.400.85✅ 合格
P（磷）≤0.0350.018✅ 合格
S（硫）≤0.0350.012✅ 合格
碳當量（Ceq）：Ceq是衡量鋼材焊接性的指標，越低越好。SS400的Ceq應≤0.42%，計算式：Ceq = C + Mn/6 + (Cr+Mo+V)/5 + (Ni+Cu)/15。

4. 如何驗讀力學性質

規格降伏強度 ReL (MPa)抗拉強度 Rm (MPa)延伸率 El(%)
SS400≥245（t≤16mm）400～510≥21
SN400B235～355400～510≥22（降伏比≤0.80）
SS540≥390≥540≥15
A36（ASTM）≥250400～550≥20
SN材特別注意：建築用SN400B除了抗拉強度外，還要求「降伏比（YS/TS）≤0.80」，確保地震時構件具有充分塑性變形能力，一般SS400不要求此項。

5. 爐次號碼的重要性

爐次號碼是鋼材追溯的核心。每批鋼材出廠時，鋼板上用鋼印或漆字標記爐次，材質書上記錄相同爐次的試驗數據。驗收時應核對：鋼板上的爐次印記 → 材質書上的爐次號碼 → 兩者是否一致。若不一致，應拒絕接收或要求廠商重新開具對應的材質書。

6. 第三方認證

重大工程（橋梁、高樓鋼骨）通常要求：

  • 原廠材質書（Original Mill Certificate）：非複印件，應有鋼廠原始公章。
  • 第三方驗証（TPI）：由SGS、BV、Intertek等在鋼廠出貨前進行尺寸複驗與取樣複驗。
  • 數位驗證：中鋼、日本大廠提供電子材質書，可透過QR Code驗證真偽。
防偽提醒：台灣市場曾發生仿造材質書案例，重要工程建議指定向一級盤商採購，並要求附上鋼廠官方電子材質書。

7. 材質書保存

  • 工程完工後材質書應與施工圖說一同存檔，建議保存至少15年。
  • 每張材質書應與對應的到料單、使用部位紀錄一起管理。
  • 以爐次號碼為索引建立電子檔，方便日後查詢。
  • 竣工後業主可能要求提供完整的材質書彙整冊（Material Register）。
